# SEGSOL
App web de gestión de personal y logística (archivo único `index.html`).

Módulos: Registro de Personal/Postulantes, Asistencia, Mapas y Rutas (Avance de Rutas, Dashboard MR, Análisis de Rechazos), Liquidaciones, Flota, Kardex de EPP.

## Uso
Abrir `index.html` en el navegador (o con la extensión Live Server de VS Code). Datos en localStorage + sincronización con Firebase Firestore.
